# 黑白灰 UI 改版验证

基线为 GitHub 主分支 e31c9e892d9513dd67737cec577788086d0b2f98。

## 改动范围

- 黑白灰界面与少量灰阶渐变装饰；橙红色仅用于风险数字、重点证据。
- 首页中英文标题与介绍重新组织。其他分析文案、数据和规则不变。
- 调查结果出现后收缩首页区域；重新排列现有追踪节点。
- 表单支持 Enter，添加输入标签与聚焦样式；结果标签支持左右键、Home、End。
- 字体为自托管 Manrope 与 Noto Sans SC，保留 OFL 授权。中文字体覆盖 GB2312 常用字符、界面字符与常用标点；罕见字由系统字体补足。

## 验证方法

运行 `node qa/verify-content.mjs`。38 项对照覆盖中英文的四个标签、初始/空/加载/有数据状态，以及三种原因验证状态。

对照保留分析结果的文字和值，排除用户授权修改的首页区域、字标的分段排版以及装饰符号；同时检查其他 copy 字段未变。程序、接口与分析逻辑文件通过 Git diff 确认未修改。

`review-fixture.ts` 与 `UIReview.tsx` 仅用于界面验证。截图里的地址、金额、风险分数为合成数据。该组件没有挂载到生产路由。需要恢复本地检查时，可以临时将 UIReview.tsx 复制到 app/ui-review/page.tsx，完成后移出 app。

已在浏览器检查桌面首页、中英文切换、手机首页、手机追踪、证据展开与键盘切换。Figma 包含可编辑桌面/手机首页，设计链接：
https://www.figma.com/design/lBo7hoDm4286mTKK4CmL9Z?node-id=5-196

真实链上请求与 AI 接口未在本轮重新调用。原版证据列表先截取 30 条再排序的逻辑仍保留，本次没有合并逻辑修正。

本地依赖通过已有 node_modules 的目录联接复用。该环境需要使用 `next build --webpack` 验证；普通安装依赖的环境可以使用项目原来的 `npm run build`。
